# ArchConstruct 3D — Enterprise Architectural Assembly & BIM Construction Visualizer

An interactive, high-fidelity 3D Architectural Construction & Assembly Visualizer built with **React 19**, **Three.js**, **TypeScript**, and **Tailwind CSS**.

Featuring **20 Master Architectural Blueprints**, multi-phase BIM LOD-400 structural animation, synchronized spoken voice narration, true orthographic CAD projections, dynamic SVG callout leader lines, and multi-axis exploded view disassembly.

## 🏗️ 8-Phase BIM Assembly Simulation

Every building animates sequentially across 8 industry-standard construction milestones (LOD 400 fabrication level, verified to ISO 19650):

1. **Phase 01: Site Preparation & Earthwork** — Sub-grade excavation, slurry walls, gnss survey datum stakes, leveling blinding concrete.
2. **Phase 02: Substructure & Foundation** — Reinforced concrete raft bunker slabs, caisson piles, footings, and tanked waterproofing barriers.
3. **Phase 03: Primary Superstructure** — Structural steel framing, moment-resisting columns, diagrid trusses, or glulam arches.
4. **Phase 04: Slabs & Vertical Circulation** — Post-tensioned floor decks, cantilevered planter trays, shear cores, and stairs.
5. **Phase 05: Building Envelope & Facade** — Unitized low-E curtain walls, triple-glazing, rainscreen cladding, and entrance portals.
6. **Phase 06: Interior Architecture & MEP** — Mass timber flooring, acoustic partition zoning, geothermal heat pumps, and living walls.
7. **Phase 07: Roof Structure & Skylights** — Cantilevered roof slabs, zinc oculus lanterns, tensile membranes, and solar PV arrays.
8. **Phase 08: Civic Landscape & Finishes** — Plaza pavers, reflecting pools, live specimen trees, flagstones, and LED uplighting.

## 💥 Multi-Axis Exploded View Disassembly (EXP: 0% – 100%)

Drag the **EXP** slider in the control toolbar or press <kbd>E</kbd> to dynamically disassemble any model:
- **Phase 0 (Excavation)**: Drops downward into bedrock ($Y: -9.0\text{m}$).
- **Phase 1 (Foundation)**: Separates beneath the superstructure ($Y: -5.0\text{m}$).
- **Phase 2 (Superstructure)**: Remains as the central anchored structural datum.
- **Phase 3 (Slabs & Decks)**: Ascends diagonally in tiered floor levels ($Y: +5.0\text{m}$).
- **Phase 4 (Curtain Wall)**: Peels radially outward away from the perimeter ($\pm 11.0\text{m}$).
- **Phase 5 (MEP & Interiors)**: Steps out on opposite axes for room inspection ($\mp 6.0\text{m}$).
- **Phase 6 (Roof & Spire)**: Launches high into the sky above the structure ($Y: +14.5\text{m}$).
- **Phase 7 (Landscape & Boreholes)**: Extends outward along ground margins with geothermal coils exposed.

When returning the EXP slider to `0%`, the model snaps seamlessly back to the active construction progress.

## 🎙️ Spoken Technical Voice Narration (Web Speech API)

- Fully automated voice commentary synchronized with each construction milestone.
- Narrates architectural design philosophy, material specifications, fabrication tolerances, trade specialties, and OSHA/ISO safety protocols.
- Dedicated controls: Toggle voice on/off (<kbd>V</kbd>), replay narration (<kbd>Shift</kbd>+<kbd>V</kbd>), and adjust playback speeds (0.5x, 1x, 2x).

---

## 📐 True Orthographic CAD Camera vs. Perspective

Switch instantly between Perspective and True Orthographic CAD Camera (<kbd>O</kbd> key or toolbar button):
- **Perspective Camera**: Human-eye optics with natural depth convergence; ideal for cinematic flythroughs.
- **True Orthographic CAD Camera**: Strictly parallel projection without foreshortening; ideal for architectural elevations, floor plans, and true dimension measurements.

---

## 🎨 Three Real-Time Render Modes

- **PBR Realistic** (<kbd>P</kbd>): Physical PBR shaders, metallic reflections, roughness mapping, and ambient soft shadows.
- **CAD Blueprint** (<kbd>B</kbd>): Technical architectural blueprint styling with cyan line-art accents.
- **Museum Clay** (<kbd>C</kbd>): Minimalist architectural gypsum presentation model with soft ambient occlusion.

---

## 🏷️ Real-Time Dynamic SVG Callout Leader Lines

- Screen-space 2D SVG leader lines with pulsing anchor pins and 45° elbows dynamically tracked to 3D mesh world positions at 60fps.
- Click any callout pin or 3D element to inspect LOD-400 fabrication metadata, dimensions, material grades, and trade protocols.
- Callouts automatically offset and track parts in real time during exploded view expansion.

## 💻 Tech Stack

- **Frontend Core**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **3D Graphics Engine**: [Three.js](https://threejs.org/) (WebGL, PCFSoftShadowMap, PBR Physical Materials, Raycasting, OrbitControls)
- **Styling & UI**: [Tailwind CSS](https://tailwindcss.com/) (Daylight frosted glass architecture, responsive HUD panels)
- **Build System**: [Vite 6](https://vitejs.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Audio & Speech**: Procedural Web Audio API sound synthesizer + Web Speech API synthesis engine
- **Celebration Effects**: [Canvas-Confetti](https://www.npmjs.com/package/canvas-confetti)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/Rohitkumar-3103/Build_Architecture.git
cd Build_Architecture

# Install dependencies
npm install

# Start local development server with Vite HMR
npm run dev
```

Open `http://localhost:3000/` in your browser.

### Production Build

```bash
# Typecheck and bundle production assets
npm run build

# Preview production build locally
npm run preview
```
